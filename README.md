# maximo.dev — Portfólio Pessoal

Portfólio profissional de Ruan Máximo — Backend & AI Automation Engineer.

## Como usar

1. Clone este repositório
2. Coloque sua foto de perfil em `./assets/perfil-capuz.png`
3. Abra `index.html` no navegador ou publique no GitHub Pages

## Deploy no GitHub Pages

1. Crie um repositório chamado `ruangmx.github.io`
2. Faça push deste conteúdo para a branch `main`
3. Acesse `https://ruangmx.github.io`

## Estrutura

```
├── index.html          # Página principal
├── assets/
│   └── perfil-capuz.png  # Sua foto de perfil (adicione aqui)
└── README.md
```

## Stack do site

- HTML5 semântico
- CSS3 com variáveis customizadas
- JavaScript vanilla (IntersectionObserver para animações)
- Tabler Icons (CDN)
- Google Fonts (Outfit + JetBrains Mono)
- 100% responsivo (mobile-first)

## Personalização

Edite as variáveis CSS no `:root` do `index.html` para alterar cores, fontes e espaçamentos.
